  • 的deпритяжательная частица
    Другие значения из словаря (на английском)of; ~'s (possessive particle); (used after an attribute when it modifies a noun); (used at the end of a declarative sentence for emphasis)
    • 是我的。shì wǒ deЭто мой.
    • 这是我的。zhè shì wǒ deЭто моё.
  • 了leчастица завершённого действия или изменения
    Другие значения из словаря (на английском)(completed action marker); (modal particle indicating change of state, situation now); (modal particle intensifying preceding clause)
    • 怎么了？zěn me leЧто происходит?
    • 下雨了。xià yǔ leИдёт дождь.
  • 我wǒя
    Другие значения из словаря (на английском)my
    • 你不是我。nǐ bù shì wǒТы не я.
    • 我爱你。wǒ ài nǐЯ люблю тебя!
  • 是shìбыть; являться
    Другие значения из словаря (на английском)to be (followed by substantives only); correct; right; true
    • 你是人。nǐ shì rénТы человек.
    • 我们是人。wǒ men shì rénМы люди.
  • 你nǐты
    Другие значения из словаря (на английском)you (informal, as opposed to courteous 您[nin2]); you (Note: In Taiwan, 妳 is used to address females, but in mainland China, it is not commonly used. Instead, 你 is used to address both males and females.)
    • 谢谢你。xiè xie nǐСпасибо!
    • 你是谁？nǐ shì shéiТы кто?
  • 在zàiв; на; находиться
    Другие значения из словаря (на английском)to exist; to be alive; (of sb or sth) to be (located) at; (used before a verb to indicate an action in progress)
    • 我在家。wǒ zài jiāЯ дома.
    • 在下雨。zài xià yǔИдёт дождь.
  • 不bùне; нет
    Другие значения из словаря (на английском)not so; un-
    • 我不去。wǒ bù qùЯ не пойду.
    • 我不知道。wǒ bù zhī dàoЯ не знаю.
  • 有yǒuиметь; есть
    Другие значения из словаря (на английском)with; -ful; -ed
    • 有人吗？yǒu rén maЕсть здесь кто-нибудь?
    • 你有吗？nǐ yǒu maУ тебя есть?
  • 他tāон
    Другие значения из словаря (на английском)(third-person singular) (since the early 20th century, usu. male) he; his; another; some other (as in 他日[ta1 ri4] and 他人[ta1 ren2])
    • 他是谁？tā shì shéiКто он?
    • 他来了。tā lái leОн пришёл.
  • 这zhèэтот; этоТрадиционное написание: 這
    Другие значения из словаря (на английском)(pronoun) this; these; the (followed by a noun); these (followed by a classifier) (in this sense, commonly pr. [zhei4], esp. in Beijing)
    • 这是什么？zhè shì shén meЧто это?
    • 这是真的。zhè shì zhēn deЭто правда.
  • 个gèуниверсальное счётное словоТрадиционное написание: 個
    Другие значения из словаря (на английском)(classifier used before a noun that has no specific classifier)
    • 他是个好人。tā shì gè hǎo rénОн хороший человек.
    • 我是个老师。wǒ shì gè lǎo shīЯ учитель.
  • 和héи; сТрадиционное написание: 咊
    Другие значения из словаря (на английском)(joining two nouns) and; together with; with (Taiwan pr. [han4]); (math.) sum
    • 我和他是朋友。wǒ hé tā shì péng youОн мой друг.
    • 我想和他说话。wǒ xiǎng hé tā shuō huàЯ хочу с ним поговорить.
  • 人rénчеловек; людиСчётное слово: 个、位
    • 多少人？duō shao rénСколько человек?
    • 我是好人。wǒ shì hǎo rénЯ хороший человек.
  • 说shuōговорить; сказатьТрадиционное написание: 說
    Другие значения из словаря (на английском)to talk; to explain; to comment
    • 我能说。wǒ néng shuōЯ могу говорить.
    • 你说吗？nǐ shuō maТы скажешь?
  • 我们wǒ menмыТрадиционное написание: 我們
