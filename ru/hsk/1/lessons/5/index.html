  • 事shìделоСчётное слово: 件、桩、回
    Другие значения из словаря (на английском)item; work; affair
    • 对事不对人。duì shì bù duì rénКритикуй поступок, а не человека.
    • 我还有点事。wǒ hái yǒu diǎn shìУ меня ещё есть кое-какие дела.
  • 它tāоно (о животных и предметах)
    Другие значения из словаря (на английском)it (pronoun for an animal)
    • 它很大。tā hěn dàОн очень большой.
    • 它太大了。tā tài dà leОн слишком большой.
  • 后hòuпосле; сзади
    Другие значения из словаря (на английском)empress; queen; (archaic) monarch; ruler
    • 我们三小时后见吧。wǒ men sān xiǎo shí hòu jiàn baМы встретимся через три часа.
  • 家jiāдом; семьяСчётное слово: 个Традиционное написание: 傢
    Другие значения из словаря (на английском)(polite) my (sister, uncle etc); classifier for families or businesses; refers to the philosophical schools of pre-Han China
    • 我在家。wǒ zài jiāЯ дома.
    • 我想家。wǒ xiǎng jiāЯ хочу домой.
  • 你们nǐ menвы (мн. ч.)Традиционное написание: 你們
    • 你们呢？nǐ men neА ты?
    • 你们好吗？nǐ men hǎo maКак поживаете?
  • 前qiánвпереди; перед
    Другие значения из словаря (на английском)forward; ahead; first; top (followed by a number)
    • 我想在五点前到家。wǒ xiǎng zài wǔ diǎn qián dào jiāЯ бы хотел прийти домой в пять часов.
    • 五百年前是一家。wǔ bǎi nián qián shì yī jiāПятьсот лет назад они были одной семьёй.
  • 时间shí jiānвремяТрадиционное написание: 時間
    Другие значения из словаря (на английском)(concept of) time; (duration of) time; (point in) time
    • 时间到了。shí jiān dào leВремя истекло.
    • 我有时间。wǒ yǒu shí jiānУ меня есть время.
  • 怎么zěn meкак; почемуТрадиционное написание: 怎麼
    Другие значения из словаря (на английском)how?; what?; why?
    • 怎么了？zěn me leЧто происходит?
    • 你怎么了？nǐ zěn me leЧто с тобой?
  • 爱àiлюбитьТрадиционное написание: 愛
    Другие значения из словаря (на английском)to be fond of; affection; to be inclined (to do sth)
    • 我爱你。wǒ ài nǐЯ люблю тебя!
    • 我爱她。wǒ ài tāЯ люблю её.
  • 这些zhè xiēэтиТрадиционное написание: 這些
    • 我找到了这些。wǒ zhǎo dào le zhè xiēЯ нашёл эти.
    • 这些苹果很小。zhè xiē píng guǒ hěn xiǎoЭти яблоки маленькие.
  • 喜欢xǐ huanнравиться; любитьТрадиционное написание: 喜歡
    Другие значения из словаря (на английском)to be fond of
    • 你喜欢吗？nǐ xǐ huan maНравится?
    • 我喜欢他。wǒ xǐ huan tāОн мне по душе.
  • 吃chīесть; кушать
    Другие значения из словаря (на английском)to consume; to eat at (a cafeteria etc); to eradicate; to destroy
    • 我喜欢吃。wǒ xǐ huan chīЯ люблю поесть.
    • 你还在吃。nǐ hái zài chīТы всё ещё ешь.
  • 谁shéiктоТрадиционное написание: 誰
    Другие значения из словаря (на английском)also pr. [shui2]
    • 他是谁？tā shì shéiКто он?
    • 你是谁？nǐ shì shéiТы кто?
  • 新xīnновый
    Другие значения из словаря (на английском)newly; meso- (chemistry)
    • 他是新来的。tā shì xīn lái deОн новенький.
    • 我是新来的。wǒ shì xīn lái deЯ здесь новичок.
  • 找zhǎoискать
    Другие значения из словаря (на английском)to try to find; to call on sb; to find; to seek
    • 我在找你。wǒ zài zhǎo nǐЯ ищу тебя.
    • 你在找谁？nǐ zài zhǎo shéiКого ты ищешь?
