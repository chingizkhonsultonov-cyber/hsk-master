  • 像xiàngбыть похожим; как
    Другие значения из словаря (на английском)to resemble; to be like; to look as if; such as
    • 你好像很忙。nǐ hǎo xiàng hěn mángТы, кажется, занят.
    • 看起来像天书。kàn qǐ lai xiàng tiān shūЭто для меня китайская грамота.
  • 向xiàngк; в сторону
    Другие значения из словаря (на английском)to face; to turn towards; direction; to support
    • 一直向前走对吧？yī zhí xiàng qián zǒu duì baВсё время прямо, да?
    • 是为了要向前走！shì wèi le yào xiàng qián zǒuЭто чтобы идти вперёд!
  • 认为rèn wéiсчитать; полагатьТрадиционное написание: 認為
    Другие значения из словаря (на английском)to consider; to feel
    • 我认为你错了。wǒ rèn wéi nǐ cuò leЯ думаю, что ты ошибаешься.
    • 我也这么认为。wǒ yě zhè me rèn wéiЯ тоже так думаю.
  • 起qǐвставать; подниматься
    Другие значения из словаря (на английском)to raise; to set out; to start
    • 我不早起。wǒ bù zǎo qǐЯ рано не встаю.
    • 他没有早起。tā méi yǒu zǎo qǐОн не встал рано.
  • 应该yīng gāiследует; долженТрадиционное написание: 應該
    Другие значения из словаря (на английском)ought to; must
    • 我应该知道。wǒ yīng gāi zhī dàoМне надо это знать.
    • 你应该听听。nǐ yīng gāi tīng tīngТебе стоит послушать.
  • 带dàiбрать с собой; приносить; поясСчётное слово: 条Традиционное написание: 帶
    Другие значения из словаря (на английском)girdle; ribbon; tire
    • 把它带给我。bǎ tā dài gěi wǒПринеси его мне.
    • 你带书没有？nǐ dài shū méi yǒuВы принесли книги?
  • 种zhǒngвид; сортТрадиционное написание: 種
    Другие значения из словаря (на английском)seed; species; classifier for types, kinds, sorts
    • 你不喜欢哪种书？nǐ bù xǐ huan nǎ zhǒng shūКакие книги ты не любишь?
    • 这种钱包你卖吗？zhè zhǒng qián bāo nǐ mài maУ вас продаются такие кошельки?
  • 发现fā xiànобнаружить; заметитьТрадиционное написание: 發現
    Другие значения из словаря (на английском)to become aware of; to find; to detect
    • 他发现自己错了。tā fā xiàn zì jǐ cuò leОн увидел, что он неправ.
    • 我发现读这本书很难。wǒ fā xiàn dú zhè běn shū hěn nánМне трудно читать эту книгу.
  • 一定yí dìngобязательно; непременно
    Другие значения из словаря (на английском)surely; necessarily; fixed; a certain (extent etc)
    • 我一定是忘了。wǒ yī dìng shì wàng leДолжно быть, я забыл.
    • 到外国一定很贵。dào wài guó yī dìng hěn guìЕздить за границу наверняка дорого.
  • 生活shēng huóжизнь; жить

    • 生活怎么样？shēng huó zěn me yàngКак поживаете?
    • 我不想过这样的生活。wǒ bù xiǎng guò zhè yàng de shēng huóЯ не хочу так жить.
  • 一直yì zhíвсё время; прямо
    Другие значения из словаря (на английском)straight (in a straight line); continuously; always; all the way through
    • 你一直忙。nǐ yī zhí mángТы всегда занят.
    • 我一直在找你。wǒ yī zhí zài zhǎo nǐЯ тебя искал.
  • 发生fā shēngпроисходить; случатьсяТрадиционное написание: 發生

    • 在哪里发生？zài nǎ li fā shēngГде это случилось?
    • 那有时会发生。nà yǒu shí huì fā shēngИногда такое бывает.

  • 为了wèi leчтобы; радиТрадиционное написание: 為了
    Другие значения из словаря (на английском)for the purpose of

    • 我为了让她们听懂所以讲得很慢。wǒ wèi le ràng tā men tīng dǒng suǒ yǐ jiǎng de hěn mànЯ говорил медленно, чтобы они могли меня понять.
  • 一样yí yàngодинаковый; такой жеТрадиционное написание: 一樣

    • 这次不一样。zhè cì bù yī yàngНа этот раз всё иначе.
    • 他和我一样高。tā hé wǒ yī yàng gāoОн со мной одного роста.
  • 只是zhǐ shìвсего лишь; только
    Другие значения из словаря (на английском)merely; nothing but; simply
    • 她只是个孩子。tā zhǐ shì gè hái ziОна всего лишь ребёнок.
    • 我只是想要你来。wǒ zhǐ shì xiǎng yào nǐ láiЯ просто хочу, чтобы ты пришёл.
  • 世界shì jièмирСчётное слово: 个
    • 你好，世界！nǐ hǎo shì jièЗдравствуй, мир!
    • 我想周游世界。wǒ xiǎng zhōu yóu shì jièЯ хотел бы путешествовать вокруг света.

  • 重要zhòng yàoважный
    Другие значения из словаря (на английском)significant; major
    • 这不重要。zhè bù zhòng yàoЭто не важно.
    • 这个不重要。zhè ge bù zhòng yàoЭто не важно.
  • 必须bì xūобязательно; долженТрадиционное написание: 必須
    Другие значения из словаря (на английском)to have to; compulsory; necessarily
    • 你必须去做。nǐ bì xū qù zuòТы должен это сделать.
    • 我必须吃药。wǒ bì xū chī yàoЯ должен принимать лекарства.
